## 议题《安药智能药盒》简介

面向需要长期规律服药的慢病与罕见病人群的用药依从性系统，由 App、智能药盒、智能手表三端联动：

- 智能药盒内置开盒感应，记录每一次取药动作，不依赖患者自行打卡；
- 智能手表与药盒做蓝牙握手，确认取药行为真实发生、人在场；
- App 负责提醒、记录与家属可见，照护者无需反复追问。

物料成本控制在 150 元以内，外形做成充电宝式隐蔽外观，让长期服药不带病耻感。该项目由 Khub 罕见病开源社区以开源协作方式共建，方案可被修改、本地化、由患者家庭自行取用。
